# DepthWizard — PHASE 2 MODIFY results (log1p target transform)

_Appended 2026-08-27. The Phase-1 content ABOVE this line is the original record and is preserved unchanged (§20). ## The diagnosis this run tested

Phase-1 scatter plots showed Baseline C **ceilings at ~14 m** — it cannot predict tall structures. The output head is a linear `Conv2d(w,1,1)` with **no activation, clip, or cap**, so the ceiling is NOT an implementation artifact. It is a *learned* limitation: masked-L1 loss on raw-meter targets, under extreme low-height class imbalance (89% of building pixels are ≤15 m), drives the head toward the conditional median and it under-fits the rare tall peaks. The single minimal, evidence-justified modification (§13): train on **`log(1+h)`**, invert with `expm1` at predict time *before* resizing. This is a pure pointwise reparameterization — the ONLY variable changed vs the original C.

## Phase-2 (log1p) checkpoint decision

### Recommendation: **MODIFY AGAIN** (keep log1p; the decisive building/tall weakness is unresolved by one transform)

The minimal modification did exactly what the diagnosis predicted — it lifted the ~14 m ceiling in the tall regime (~1.24 m on >14 m building pixels, bias less negative in every tall bin) at essentially zero headline cost, and it generalizes slightly better in-domain. **Keep it.** But it is NOT the fix that changes the verdict:

1. On the product-critical **building** class cross-city, the learned head still **ties trivial affine** (C 5.48 ≈ B 5.49). C's overall cross-city win is almost entirely on the non-building ground majority.
2. The ceiling is only **partially** lifted — the 40+ m bin still has −23 m bias (a 40 m arena is still predicted as a ~17 m slab). The error maps (`figures/challenge_*`) show log1p now *can* emit tall values but places them **crudely** (it overshoots a thin ridge while under-predicting the broad mass) → the bottleneck is spatial features / receptive field / loss-weighting for rare tall-building pixels, not the target parameterization alone.

This is **not ABANDON** (signal is real, r=0.35; the head fits; it beats affine overall; the tall regime is demonstrably improvable; oracle headroom exists: building MAE 5.48 → 2.81). A reviewer who weights the robust overall cross-city win could reasonably read it as a **QUALIFIED GO** and proceed to build the product around the log1p head while documenting tall buildings as a known limitation. **The human makes the final call at this checkpoint.** The per-variant `decide()` returns GO for both (context only — it keys on overall cross-city MAE, which is dominated by ground pixels).

## What this run does and does NOT prove

- It establishes that a **single target-space reparameterization is insufficient** to fix the tall-building regime, while confirming the ceiling diagnosis mechanically.
- It does **not** establish accuracy on **Indian ISRO optical imagery** (the final domain), and does **not** build the product.
- It is one controlled modification, city-held-out on the unofficial DFC2019 mirror only. **STOP for human review** (§19/§28).
