# DepthWizard â— PHASE 13B results (ordinal height classification)

_Appended 2026-08-27. All prior phases are preserved unchanged. This is a controlled single-variable test against continuous L1 regression: **Frozen Depth Anything V2 + SmallFusionUNet**, but using **ordinary 8-bin multiclass cross-entropy** instead of continuous regression. Target: 0-2, 2-5, 5-10, 10-15, 15-20, 20-30, 30-40, >40 m. Data: 9-city train (Arm B), NewYork test. Evaluated by: scripts/run_phase13b_full.py. Full report:

## Hypothesis & motivation

Previous experiments established a ~14 m **prediction ceiling** on buildings. The regression hypothesis was that L1/L2 metric loss penalizes geometric errors, causing the network to defensively predict the ground/median height instead of risking massive penalties on tall outliers. **Test:** Does removing continuous regression pressure by switching to cross-entropy (where predicting 0m vs 30m incurs the same penalty if true is 40m) allow the network to finally recover the tall-height tail?

## Results & class collapse (mean over seeds 0, 1)

**The experiment yielded an extreme class collapse.** Despite the >40 m class having nearly 2 million pixels in the training set, the network completely refused to predict the top classes on the test set.

- **Overall Accuracy:** 55.8% (seed 0)
- **Macro F1:** 0.102 (seed 0)
- **>30m Recall:** 0.000
- **>40m Recall:** 0.000
- **>40m Precision:** 0.000

## Scientific Verdict: NOT SUPPORTED

**The classification hypothesis is NOT SUPPORTED.**

The hypothesis assumed that the unbounded geometric penalty of L1 regression was suppressing the tail, and that a class-based cross-entropy formulation would free the network to predict extreme heights. Without a reliable input signal to separate the classes, the classifier safely defaults to the dominant distribution modes (ground and mid-rise) to minimize expected cross-entropy.
