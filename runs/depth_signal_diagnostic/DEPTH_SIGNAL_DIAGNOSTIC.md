## 9. Connection to prior experiments (§17)

- The ~14 m prediction ceiling survived the target transform (Phase-2), loss reweighting (Phase-3/4) and capacity/receptive-field (Phase-5). This diagnostic tests the remaining upstream hypothesis: the INPUT depth signal itself.
- If the signal is strong here -> the next lever is data/training/calibration.
- If tall signal is weak but oracle recovers it -> scene-scale ambiguity (per-image normalization / metric cue).
- If BOTH global and oracle are weak on the tall tail -> the frozen DA-V2 prior lacks sufficient absolute tall-height information and a different metric/physical cue is required.

## 10. Limitations

- Unofficial DFC2019 mirror, preprocessed nDSM (ground floored to 0); single training city (JAX), single cross-city test (OMA).
- DA-V2 depth is scale/shift-ambiguous and near-nadir camera-depth variation is negligible, so it encodes learned appearance priors, not measured geometry.
- Tall pixels are sparse; tall-bin statistics have wider uncertainty. Oracle is an upper bound that peeks at GT and is not deployable.
- This diagnostic does NOT establish final model / ISRO / DSM / DEM / GeoTIFF / 3D / production accuracy (§26).
