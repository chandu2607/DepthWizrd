# Phase 63 — Training Split Plan

## Status

This is a design-only plan until a valid benchmark exists.

## Recommended future structure

- Train: one Indian mountainous region
- Validation: geographically distinct region within the same terrain regime
- Test: completely held-out Indian mountain region

## Current issue

No real benchmark is available yet, so the split cannot be executed with actual evidence.

## Scientific requirement

The final test region must never be used for model selection or threshold tuning.
