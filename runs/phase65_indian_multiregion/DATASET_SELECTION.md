# Phase 65 — Indian Multi-Region Dataset Selection

## Decision

The project currently has one verified real Indian mountainous benchmark pair from Phase 64: Uttarakhand.

A second and third region were identified as geographically separate candidates: Himachal Pradesh and Sikkim. These are scientifically appropriate for train/validation/test separation, but they are not yet accepted as final benchmark regions because the paired optical + elevation files have not yet been downloaded, read, aligned, and matched with a valid high-resolution building or height reference.

## Scientific position

- No Indian train/validation/test split is accepted yet.
- Phase 64 remains the only verified real Indian benchmark pair.
- No high-resolution building-height ground truth has been verified for any Indian region in this workspace.
- The project stops before training, exactly as required by the evidence gate.
